# USBridge Hardware Assets
This repository contains the mechanical and electrical source files for the USBridge appliance.

## Repository Structure
* **/3D_Models** - Enclosure STL and STEP files.
* **/PCBs** - Gerber files and schematics for auxiliary modules.
